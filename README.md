# YuvaIntern Week 1 – Titanic Data Preprocessing

## AI Pioneers Internship – Machine Learning

This project was completed as part of **Week 1** of the YuvaIntern AI Pioneers Internship (Machine Learning Internship).

The objective of this task is to demonstrate a complete Python-based data preprocessing workflow using the Titanic passenger dataset.

## Project Objectives

The project covers:

- Loading and inspecting a dataset
- Identifying missing values
- Feature selection
- Missing-value treatment
- Categorical variable encoding
- Numerical feature normalization
- Exploratory Data Analysis (EDA)
- Exporting a clean machine-learning-ready dataset

## Dataset

The project uses the Titanic passenger training dataset containing:

- **891 rows**
- **12 original columns**
